# Project 04: NLP Sentiment Analysis

## Overview

This project develops natural language processing
models to classify customer reviews as positive
or negative. ( an a machine-learning algorithm understand whether a written review expresses a positive or negative opinion?)

## Objectives

- Clean and preprocess textual data.
- Apply tokenization and lemmatization.
- Convert text into numerical features using TF-IDF.
- Train Naive Bayes and Logistic Regression models.
- Compare and evaluate model performance.

## Technologies

Python, Pandas, NumPy, NLTK,
Scikit-learn, Matplotlib.
